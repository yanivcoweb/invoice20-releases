# Invoice 2.0

המתקין של Invoice 2.0 ל־Windows. אין כאן קוד, רק גרסאות.

**להורדת הגרסה האחרונה:** [Releases ← Latest](https://github.com/yanivcoweb/invoice20-releases/releases/latest),
והקובץ `Invoice-2.0-Setup-<גרסה>.exe`.

- המתקין לא חתום, ולכן Windows יזהיר בהתקנה הראשונה: "More info" ← "Run anyway".
- אחרי ההתקנה התוכנה מתעדכנת מכאן בעצמה: בהגדרות, "בדוק עדכונים".
- כדי להתחבר צריך קוד צירוף מהמפעיל.
